## V3.0 - Full Version with Admin Panel (Code Only)
The V3.0 folder contains the complete application with PHP backend, admin panel, and image upload functionality.

**Note:** V3.0 requires PHP hosting and cannot run on GitHub Pages. The code is available for review.
### Features in V2.0(No Admin Panel)
- HTML CSS Javascript
- Responsive design
- Filters
- Search bar
- Dynamic insertion of products from products-info.js

#### In V2.0 needed to manually insert and edit products Object in products-info.js 


### Features in V3.0 (Code)
- PHP admin panel with session authentication
- Full CRUD operations (Create, Read, Update, Delete)
- Image upload with automatic folder management
- JSON data storage with JS file synchronization
- Edit/Delete products with recursive file deletion

- ### Features in V4.0 (Code)
- Pretty much Same as V3.0 
- Moved From Saving items in products.json to using a Database(MySql)
- MySql Apache server 
- Full CRUD operations are still Available
